이 **NBA 선수 통계 데이터셋 샘플**에는 **1,000개 레코드**가 포함되어 있으며, **Bright Data API**를 사용해 추출되었습니다.

## 데이터 포인트

| 필드 이름 | 설명 |
|------------|-------------|
| `url` | 선수의 프로필 페이지로 직접 연결되어 상세 정보를 확인할 수 있는 ESPN URL입니다. |
| `player_name` | NBA 선수의 전체 이름입니다. |
| `player_games_played` | 시즌 동안 선수가 출전한 총 경기 수입니다. |
| `player_games_started` | 시즌 동안 선수가 선발 출전한 총 경기 수입니다. |
| `player_minutes_per_game` | 선수의 경기당 평균 출전 시간입니다. |
| `player_points_per_game` | 선수의 경기당 평균 득점입니다. |
| `player_offensive_rebounds__per_game` | 경기당 평균 공격 리바운드 수입니다. |
| `player_defensive_rebounds_per_game` | 경기당 평균 수비 리바운드 수입니다. |
| `player_rebounds_per_game` | 선수의 경기당 평균 총 리바운드 수입니다. |
| `player_assists_per_game` | 선수의 경기당 평균 어시스트 수입니다. |
| `player_steals_per_game` | 선수의 경기당 평균 스틸 수입니다. |
| `player_blocks_per_game` | 선수의 경기당 평균 블록 수입니다. |
| `player_turnovers_per_game` | 선수의 경기당 평균 턴오버 수입니다. |
| `player_fouls_per_game` | 선수의 경기당 평균 파울 수입니다. |
| `player_assist_to_turnover_ratio` | 선수의 어시스트 대비 턴오버 비율입니다. |
| `team` | 시즌 동안 선수가 소속된 NBA 팀입니다. |
| `season_type` | 데이터가 정규 시즌인지 플레이오프인지 나타냅니다. |
| `season_year` | 통계가 집계된 NBA 시즌의 연도입니다. |


## 활용 사례

### 1. 선수 퍼포먼스 분석
여러 시즌에 걸친 개별 선수의 퍼포먼스를 분석하여 상위 선수를 식별하고 팀 전략을 개선할 수 있습니다.

### 2. 판타지 농구 인사이트
과거 선수 통계를 활용해 판타지 농구 리그를 위한 인사이트를 생성하고, 선수 선택과 예측을 지원할 수 있습니다.

### 3. 스포츠 저널리즘 및 리포팅
스포츠 기사에 심층적인 통계 분석을 제공하여 선수 퍼포먼스에 대한 데이터 기반 인사이트로 리포팅을 강화할 수 있습니다.
